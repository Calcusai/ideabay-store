# IdeaBay Renting Store website

A fast static site focused on SEO for **IdeaBay Renting Store** (camera and gear rental, Maharagama, Colombo).
It's plain HTML, CSS and JS, generated by a small **Node.js** script with **zero dependencies**. It's built for **GitHub + Vercel**.

## Project layout
```
data.js           ← all content: gear, prices, kits, FAQs, contact details (edit this)
build.js          ← generator: writes every page, the sitemap and schema to /site
static/           ← style.css, main.js, logo icons, og.png, and images/ for gear photos
scripts/check.js  ← checks for broken links, invalid schema and duplicate titles
vercel.json       ← Vercel build settings, clean URLs, cache and security headers
```
`site/` is the build output. It's git-ignored because Vercel builds it on every push.

## Run locally
```bash
npm run build      # build to ./site
npm run check      # check links, schema and titles
npm run dev        # build and preview at http://localhost:3000
```
This needs Node 18 or newer. There's nothing to `npm install`.

## Deploy: GitHub + Vercel
1. Push this folder to a new GitHub repo.
2. On vercel.com, choose **Add New → Project**, import the repo, and click **Deploy**.
   `vercel.json` already sets the build command (`npm run build`) and the output folder (`site`), so you don't need to change any settings.
3. Under **Settings → Domains**, add your domain.
4. Set `SITE.url` in `data.js` to that domain and push. Canonical tags, the sitemap and schema all use it.

Every push to `main` redeploys the site automatically, and pull requests get preview URLs.

## Editing content
- **Prices:** set `price: 6500` on an item. It shows "Rs. 6,500 / day" and adds Offer schema for Google. `null` shows "DM for rate".
- **Photos:** add `static/images/<item-slug>.jpg` (or `.webp`/`.png`). Square images of about 1000px with a white background match the Facebook post style. They're picked up automatically.
- **New gear:** copy an item block in `ITEMS` and give it a unique `slug` and an existing `cat`. Its page, sitemap entry and links are generated for you.
- **Hours:** `SITE.hours = "Mo-Su 08:00-20:00"`.

## After launch
- Submit `https://yourdomain/sitemap.xml` in Google Search Console.
- Add the website link to your Google Business Profile and the Facebook page "About" section.

## SEO included
- 32 indexable pages: home, the full catalog, 5 category pages, 19 gear pages, kits, how it works, FAQ, about and contact.
- A unique `<title>`, meta description and canonical tag on every page, plus Open Graph/Twitter cards with a branded share image.
- JSON-LD: Store (LocalBusiness), WebSite with SearchAction, BreadcrumbList, Product, ItemList, FAQPage and HowTo.
- `sitemap.xml`, `robots.txt`, web manifest and favicons.
- All content is in the HTML (JS only runs the filter and menu), so pages load fast and are easy to crawl.

## Storefront refresh
The homepage and catalog include all 19 listings. Compressed WebP assets in `static/images/` are generated from the supplied `items/` photos; original files are preserved. `showreel.mp4` is copied into the build and loaded only when requested by the visitor. The poster is extracted from the supplied reel.

The catalog matches the supplied price list: 19 named items with daily LKR prices across Cameras, Lenses, Audio, Lighting and Other. Kit suggestions reference only current items.

SEO checks cover internal links, local image/video references, canonical and description presence, unique titles and valid JSON-LD. Search rankings and Lighthouse scores require separate measurement on the deployed domain; no score or ranking is guaranteed.

The hero features six equipment slides with autoplay, numbered selectors, arrows, swipe and pause/play. Hover, keyboard focus, reduced motion and background tabs pause rotation. Availability buttons open WhatsApp with the individual gear name, category, details, URL and date prompts. Visitors must tap Send in WhatsApp. All IdeaBay logo references use the supplied root `logo.png`, copied to `/static/logo.png` during the build. `SITE.google_business` is the provided Google profile link.

Production canonical domain: `https://idebay.store`. See `SEO-LAUNCH.md` for domain, Search Console and Google Business Profile launch steps. Local business identity, geo coordinates and Google Place ID are centralized in `data.js`; nearby service areas all refer to the one Maharagama pickup location.

Additional missing equipment photos are stored locally as optimized WebP files. `image-sources.json` records the source page and source image for each downloaded asset. The softbox/stand bundle remains without a product photo until its exact model, size and stand can be confirmed.


Product search metadata and individual share previews are documented in `SEO-LAUNCH.md`. Each product has a dedicated PNG preview under `static/share/`; update it alongside its catalog photo. `npm run check` validates previews, prices and rental structured data. External search and social previews require deployment to the public domain; localhost is for development.


## Faster product images and loading state

Source photos, responsive WebP images and social PNG previews are all tracked in Git. After updating a product photo, run `npm run optimize:images` locally (requires `cwebp`, available with `brew install webp` on macOS), then commit `static/images/optimized/` along with the source photo. Deployments use these committed variants and need no image converter. Each item has 320px, 640px and 960px versions, served through responsive `srcset` attributes. The first visible hero/product photo is preloaded; catalog photos remain lazy loaded. Social preview PNGs remain separate.

A cream, forest-green and amber loading screen appears after 180ms on slower loads. It dismisses when the main photo loads or fails, with a short timeout and an independent 2.2-second fallback. It never waits for lazy images, supports reduced motion and is hidden when JavaScript is unavailable.
